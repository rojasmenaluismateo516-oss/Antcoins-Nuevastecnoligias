# 🐜💰 AntCoins - Análisis Inteligente de Gastos Hormiga

**AntCoins** es una solución educativa fullstack enfocada en el análisis y gestión de **gastos hormiga**, aquellos pequeños gastos diarios que impactan significativamente las finanzas personales.

Este repositorio corresponde al **módulo de análisis de datos en Python**, encargado de transformar datos financieros en información valiosa para la toma de decisiones.

---

## 🌍 Contexto del Problema

En la vida diaria, es común realizar pequeños gastos como:

- ☕ Café
- 🍪 Snacks
- 🚕 Transporte
- 📱 Suscripciones

Aunque parecen insignificantes, estos gastos acumulados pueden representar una parte importante del presupuesto mensual.

📌 Problemas identificados:
- Falta de control financiero
- Baja visibilidad de gastos pequeños
- Dificultad para analizar hábitos de consumo
- Ausencia de herramientas accesibles de análisis

---

## 🎯 Objetivo del Proyecto

AntCoins busca:

- 📊 Analizar hábitos de consumo
- 🔍 Identificar patrones de gasto
- 💡 Generar insights financieros
- 📈 Facilitar la toma de decisiones
- 🧠 Promover educación financiera basada en datos

---

## 🧩 Arquitectura del Sistema

El proyecto está diseñado como una solución moderna distribuida:

- 🐍 **Python (Data Layer)** → Procesamiento y análisis de datos
- ⚛️ **React (Frontend)** → Visualización de información
- ☕ **Spring Boot (Backend)** → API REST y lógica de negocio

---

## 🧠 Alcance del Módulo Python

Este módulo se encarga de:

### 📥 Ingesta de Datos
- Lectura de archivos CSV y Excel
- Estandarización de formatos de entrada

### 🧹 Limpieza de Datos
- Eliminación de valores nulos
- Corrección de inconsistencias
- Normalización de categorías

### 🔄 Transformación de Datos
- Creación de variables derivadas
- Agrupación por categorías y fechas
- Conversión de tipos de datos

### 📊 Análisis Exploratorio (EDA)
- Estadísticas descriptivas
- Distribución de gastos
- Identificación de outliers

### 📈 Generación de Métricas
- Gasto total (diario, semanal, mensual)
- Promedio por categoría
- Frecuencia de consumo

### 🔍 Detección de Patrones
- Identificación de hábitos recurrentes
- Días de mayor gasto
- Categorías predominantes
